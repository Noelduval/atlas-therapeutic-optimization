# Atlas v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the locked Atlas v1 research artifact around the single DP622-S2 / Aβ42 / S2 blinded retrospective challenge, with deterministic cached evidence, an auditable workflow, CLI commands, benchmarks, documentation, and a Streamlit UI.

**Architecture:** A typed Python package separates scientific domain objects, challenge data, evidence adapters, append-only provenance, orchestration, reporting, benchmarking, and presentation. The `demo_cached` profile runs a deterministic LangGraph-compatible workflow; all synthetic values are explicitly typed as synthetic and hidden VITA outcomes are kept in a separate repository that cannot enter workflow state before a persisted recommendation lock.

**Tech Stack:** Python 3.12, uv, Pydantic v2, Typer, LangGraph, Streamlit, pytest, Rich.

## Global Constraints

- Atlas v1 implements exactly one flagship challenge: `Atlas Challenge: Alzheimer’s Aβ Metalloprotease Optimization`.
- Canonical configuration is seed `DP622-S2`, target context `Aβ42`, cleavage system `S2`.
- The VITA paper is the scientific source; PHGDH is documentation-only future research.
- No active HER2/trastuzumab or secondary therapeutic benchmark implementation is permitted.
- Published retrospective outcomes remain outside `AtlasState`, prompts, evidence, traces, notebooks, adapters, and ranking until recommendation lock.
- Cached and synthetic values must be labeled and must never be presented as biological model output or measured evidence.
- No synthetic `kcat`, `Km`, or `kcat/Km` values are permitted.
- Catalytic geometry is evidence about geometry, never catalytic activity.
- Seed retention must terminate as `scientifically_complete`.
- The first-run UI shows only the PRD-specified challenge title, description, six metadata rows, `Load Atlas Challenge`, then `Start Campaign`.
- Exact DP622-S2, OP609-S2, and OP669-S2 sequences and supplementary assets are absent from the committed sources and must be represented as `UNAVAILABLE`.
